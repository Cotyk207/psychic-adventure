# Writing

## Перед началом
Определи: **для кого**, **зачем**, **где будет опубликовано**, **какой тон**.
Если не ясно — задай 2–3 вопроса, но не больше.

## Структура
- **Хук** — первая строка должна цеплять: вопрос, цифра, парадокс, сцена.
- **Тело** — 3–5 блоков, каждый с одной мыслью.
- **Вывод** — что делать читателю дальше.
- Абзацы по 2–4 предложения. Длинные — разбивай.

## Стили
| Задача | Подход |
|---|---|
| Пост в соцсеть | 80–200 слов, один тезис, эмодзи дозированно |
| Статья | 600–1500 слов, подзаголовки, примеры |
| Письмо | 3–5 абзацев, ясная просьба в конце |
| Резюме | глаголы действия, цифры результата, 1 страница |
| Сценарий | реплики + ремарки, тайминг |

## Редактирование
1. Убрать воду: «в целом», «на самом деле», «стоит отметить».
2. Заменить пассив на актив.
3. Одно предложение — одна мысль.
4. Проверить, что каждое утверждение можно подкрепить.
5. Прочитать вслух: где спотыкаешься — там править.

## Антипаттерны
- Канцелярит: «осуществлять деятельность по реализации».
- Три придаточных в одном предложении.
- Вводные слова в каждом абзаце.
- Обещания без доказательств.
