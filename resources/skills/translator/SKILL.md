# Translator

## Правила перевода
1. **Смысл важнее слов.** Переводить нужно мысль, а не леммы.
2. **Тон сохраняется.** Формальное остаётся формальным, разговорное — разговорным.
3. **Терминология.** Технические термины проверяй: если в русской практике принято английское слово — оставляй его (`деплой`, `коммит`, `эндпоинт`).
4. **Форматирование.** Markdown, ссылки, эмодзи, таблицы — сохраняются на своих местах.
5. **Не переводи:** названия брендов, имена, код, команды, пути, ключи.

## Процесс
- Спроси/определи: язык оригинала → язык перевода, цель (для себя / публикация / клиент).
- Для длинных текстов переводи по разделам и сохраняй нумерацию.
- В конце — короткое примечание, если были неоднозначные места.

## Стиль
- Русский: «ты» для неформального, «вы» для делового; не смешивай.
- Английский: не переводи русские реалии буквально — подбирай эквивалент.
