# Planner

## Формат плана
```
## Цель
Одно предложение: что должно получиться.

## Критерии готовности
- [ ] ...
- [ ] ...

## Шаги
1. **Название** — что делаем, что получится. (оценка)
2. ...

## Риски
- ...
```

## Правила
- 5–9 шагов — оптимум. Больше — дроби на подзадачи.
- Каждый шаг должен давать проверяемый результат.
- Сначала самый рискованный/неизвестный шаг, чтобы рано вскрыть проблемы.
- Если задача занимает больше 3–4 итераций — записывай прогресс в файл `PLAN.md` в рабочей папке.
- В конце — короткая сводка: сделано / не сделано / что дальше.

## Оценка времени
- Скрипт/правка: 5–15 мин.
- Фича в существующем проекте: 30–90 мин.
- Новый проект с нуля: 2–6 часов.
Указывай диапазон и объясняй, от чего зависит.
