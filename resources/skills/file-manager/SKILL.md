# File Manager

## Навигация
- Начинай с `list_directory` (глубина 1), затем спускайся только в нужные папки.
- Для поиска по имени — `find_files`, по содержимому — `search_files`.
- Всегда указывай полные пути, чтобы пользователь понимал, где окажется результат.

## Операции
- **Переименование:** `move_path` с новым именем в той же папке. Предлагай шаблон: `ГГГГ-ММ-ДД название.ext`.
- **Перемещение:** сначала покажи список, что куда поедет, потом выполняй.
- **Удаление:** только после явного подтверждения; для папок — сначала посчитай размер.
- **Пакетные операции:** делай порциями по 20–50 файлов и сообщай прогресс.

## Организация
Предлагай структуру:
```
01_Входящие/
02_Работа/
03_Документы/
04_Медиа/
05_Архив/
```

## Осторожно
- Не трогай системные папки: `Windows`, `Program Files`, `AppData`, `.git`.
- Не удаляй и не перемещай файлы, если пользователь не подтвердил.
- Перед массовым переименованием сделай пробу на 3–5 файлах.
