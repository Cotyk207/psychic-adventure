# Data Analysis

## Процесс
1. **Осмотр данных.** `read_file` первых строк (CSV — 5–10 строк, JSON — структуру).
2. **Очистка.** Пропуски, дубликаты, неверные типы, выбросы.
3. **Метрики.** Суммы, средние, доли, тренды, топ-значения.
4. **Визуализация.** Python + matplotlib (если установлен) или интерактивный HTML на Chart.js.
5. **Выводы.** 3–5 наблюдений, каждый с цифрой.

## Python-шаблон
```python
import pandas as pd
df = pd.read_csv('data.csv')
print(df.head(), df.dtypes, df.isna().sum())
print(df.describe())
```

## Правила
- Всегда указывай, сколько строк обработано и сколько отброшено.
- Не путай корреляцию с причинностью — говори «связь», а не «влияет».
- Округляй до разумной точности, не выдавай 12 знаков.
- Для конфиденциальных данных не выводи персональные поля в чат без необходимости.
