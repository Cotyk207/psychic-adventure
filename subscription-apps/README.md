# Отдельные приложения для сайтов ИИ

Неофициальные программы для ChatGPT, Claude, Gemini, Perplexity, Microsoft Copilot и Arena.ai открывают сайты соответствующих сервисов, не используют API-ключи и не включают подписки.

## Arena.ai: сайт внутри приложения

Отдельные Android APK и Windows EXE отображают **живой** сайт `https://arena.ai/` во встроенном браузере. Это не копия серверов Arena.ai: нужны интернет и аккаунт, а возможности и доступность зависят от сайта. Сайт, а не приложение, показывает форму входа. Встроенный браузер хранит сессию в собственном профиле, отдельно от Chrome или других браузеров; первый вход нужно выполнить именно в приложении. Повторный вход может потребоваться после истечения сессии или по требованиям Arena.ai.

Вход через Google и другие способы авторизации могут блокировать встроенные браузеры; перенос входа или cookies из системного браузера не поддерживается. Не гарантируется работа всех функций веб-сайта: например, некоторые виды загрузок и авторизации могут не поддерживаться. Выбор файлов и запрос разрешений на микрофон/камеру предусмотрены; Android-загрузки передаются Download Manager без авторизационных cookies и могут не работать для защищённых файлов. Приложение неофициальное, не связано с Arena.ai, не содержит API-ключи и не добавляет привилегий к аккаунту.

## Остальные сервисы

* **Android:** пять отдельных APK с разными ID приложения открывают сайты в Custom Tabs пользовательского браузера (или в самом браузере, если Custom Tabs не поддерживается).
* **Windows:** пять отдельных переносимых EXE. Chrome или Edge по умолчанию открывают отдельное окно браузера, другие браузеры — обычную вкладку. Используется профиль пользователя.

Доступ к платным возможностям определяется самими сервисами. Приложения не копируют файлы браузера и не отправляют запросы в API ИИ.

## Сборка

Android: `npm ci && npm run build:android`, затем `cd android && ./gradlew :service-launcher:assembleRelease`. APK находятся в `android/service-launcher/build/outputs/apk/<service>/release/`. Текущие сборки подписаны Gradle debug-ключом, стабильность которого между сборочными машинами не гарантируется.

Windows на Windows: `npm ci`, затем `npx electron-builder --win portable --config subscription-apps/arena-windows/builder.yml --publish never` для Arena и `powershell -File subscription-apps/windows/build.ps1` для остальных сервисов. Иконки — условные монограммы, не логотипы; пересоздание: `python3 subscription-apps/generate-icons.py`.
