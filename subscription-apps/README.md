# Отдельные приложения для сайтов ИИ

Независимые неофициальные программы для ChatGPT, Claude, Gemini, Perplexity, Microsoft Copilot и Arena.ai. Каждая открывает только официальный HTTPS-сайт выбранного сервиса. Это не API-клиенты и не альтернативные провайдеры PSYCHIC: интерфейс, подписки, доступные модели и стоимость определяются самим сервисом.

* **Android:** шесть отдельных APK с разными ID приложения. Открывают сайт в Custom Tabs пользовательского браузера (или в самом браузере, если Custom Tabs не поддерживается). Вход и пароли обрабатывает браузер. Можно установить все шесть рядом с PSYCHIC.
* **Windows:** шесть отдельных переносимых EXE. Если браузер по умолчанию — Chrome или Edge, сайт открывается в отдельном окне приложения браузера; иначе — обычным способом в браузере по умолчанию. Существующий профиль браузера используется совместно, аккаунт отдельно не копируется. Окна не являются встроенным в PSYCHIC браузером.

Интернет и действующая подписка на соответствующий сервис необходимы для её платных возможностей. Вход зависит от поддержки браузера и правил сервиса; гарантировать работу определённого провайдера невозможно. Эти приложения неофициальные и не связаны с владельцами сервисов; лицензии на подписки не включены. Они не запрашивают пароли, не копируют файлы браузера, не получают токены и не отправляют запросы в API ИИ.

Android-сборка: в корне репозитория подготовить Capacitor (`npm ci && npm run build:android`), затем выполнить `cd android && ./gradlew :service-launcher:assembleRelease`. APK будут в `android/service-launcher/build/outputs/apk/<service>/release/`. Текущие сборки проекта подписываются Gradle debug-ключом: это не производственная подпись и её стабильность между сборочными машинами не гарантируется.

Windows-сборка на Windows: `powershell -File subscription-apps/windows/build.ps1`. Используется компилятор .NET Framework, входящий в Windows; исходник не принимает произвольных URL или параметров. Иконки — собственные условные монограммы, а не логотипы сервисов. Для их пересоздания: `python3 subscription-apps/generate-icons.py`.

**Arena.ai:** ярлык открывает `https://arena.ai/`, а не устанавливает копию сервиса. Войдите на официальном сайте через браузер; при сохранённой сессии повторный вход обычно не нужен. Функции, доступность и срок сессии определяются Arena.ai и браузером.
